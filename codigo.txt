git status = verifica a situação dos códigos (analise do controle de versão)

git add "x" (sendo x o nome do arquivo) = adiciona o arquivo ao controle de versão

git add . = adiciona todos os arquivos ao controle de versão

git commit -m "x"(sendo x um comentario) = adiciona o arquivo ao repositório

git push = encaminha o arquivo para algum lugar (repositorio)

git remote add origin x, (sendo x o link do repositório criado) = adicionar o repositório para o arquivo

git remote set-url origin x, (sendo x a url correta do repositório, caso tenha errado) = adicionar o repositório para o arquivo

git reflog = ver o histórico de alterações de um arquivo

git reset --hard código (código esse alcançado pelo reflog) = retorna o arquivo ao commit/versão do codigo

git branch = ver as branchs disponíveis e a que esta sendo usada

git branch x (sendo x o nome da nova branch) = cria uma branch 

git checkout x (sendo x o nome da branch) = troca a branch que esta sendo usada

git checkout -b x (sendo x o nome da branch) = cria uma branch

git merge x (sendo x o nome da branch) = buscar informações da branch colocada, ~o arquivo deve ser o mais atual~

git pull = traz as atualizações mais recentes locais do arquivo
